# 真 PostgreSQL 端到端验证热切换

## 概述
热切换主链路（探活成功 → Flyway 建 PG schema → 搬行 → 原子替换 → 新后端可读）只有 SQLite 上的失败路径单测，方言、identity 列、ON CONFLICT 的 PG 语义都没被真库验证过，CI 上也从不执行。
新增 DatabaseHotSwapperPostgresIT 4 例并用 postgres:16 实跑：全链路切换、源非 SQLite 时拒绝搬数据、探活失败不写配置、切回 SQLite 保留 PG 数据。踩到两坑并修正：探针表必须用平台自带 run_ledger（搬运器契约是只在目标库已有同名表之间搬行）；源库不能用 @TempDir（被换下的连接池锁 -wal 导致误判）。surefire 纳入 **/*IT.java，ci.yml 的 backend job 加 postgres service，凭据写进 AGENT_TEST_PG_URL（IdentitySequenceSyncTest 直连需要）。
