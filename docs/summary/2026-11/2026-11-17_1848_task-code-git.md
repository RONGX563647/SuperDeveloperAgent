# 任务编码生成并参与修复分支

## 概述
平台任务只能看到内部 id（task-xxxx）与远端编号，没有稳定、可读、可口头引用的编码；自动修复分支是 agent/bugfix-<随机串>，从分支无法反查是哪个任务；新建任务也没有统一的编号规则，任务页与提交信息无法使用同一个标识。
GitIssue 增加 code 字段：项目内按分类自增（FEAT-1 / BUG-2），创建时由 SQLite 存储统一分配、更新时不可变；老库启动时按创建顺序回填已有任务；任务列表与任务页展示编码；自动修复分支改为 agent/bugfix-<code>-<短id>，保留 agent/bugfix- 前缀以兼容现有推送逻辑。
