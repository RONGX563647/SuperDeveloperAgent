# 修复能力市场不可达的TLS证书不受信bug，根因为本地SteamTools/Watt Toolkit代理工具对GitHu

## 概述
AI 开发会话（无代码提交）：修复能力市场不可达的TLS证书不受信bug，根因为本地SteamTools/Watt Toolkit代理工具对GitHu
修复能力市场不可达的TLS证书不受信bug，根因为本地SteamTools/Watt Toolkit代理工具对GitHub相关域名做了TLS中间人，其根证书仅存在于Windows系统证书库，而Java HttpClient默认仅信任JVM的cacerts，导致握手失败。修改RemoteCapabilityMarket.java中的市场HttpClient配置，新增CompositeTrustManager实现同时信任JVM默认信任库与系统根证书库，系统库不可用时自动回退原有校验逻辑，不改变原有安全语义。补充对应单元测试，全量测试通过，重启后端后能力市场可正常加载。
