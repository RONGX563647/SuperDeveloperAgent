# 规约自动化检查 v1.0

> 日期：2026-11-07 ｜ 上游：[项目规约 v1.0](项目规约-v1.0.md)
> 目标：把规约里**可机械判定**的条款，变成 `mvn verify` 会红的测试

---

## 0. 三条设计原则

1. **不引入新服务**：检查器就是 JUnit 测试，随 `mvn verify` 跑。不装 SonarQube、不配 PMD 版本、不依赖 shell。
2. **能自动的自动，不能自动的进清单**：语义类判断（"描述是否说明什么时候用"）不硬凑规则，进 PR 评审清单。
3. **规则可豁免但不能静默**：行内 `// spec-ignore: <规则号>` + 原因，且必须同步登记到项目规约 §13。

---

## 1. 三层防线

| 层 | 触发 | 跑什么 | 目的 |
|---|---|---|---|
| **提交前** | 本地 `mvn -q verify` | 全部检查器 | 5 秒内知道有没有踩红线 |
| **构建** | CI 每次构建 | 同上 + 单元测试 | 阻断合入 |
| **评审** | PR | §14 的 20 条人工清单 + 豁免审核 | 覆盖语义类条款 |

## 3. 四个检查器

| 检查器 | 位置 | 机制 |
|---|---|---|
| `ArchitectureRulesTest` | `platform/spec-checks/src/test/java/org/example/agent/arch/` | **ArchUnit** 7 条规则（依赖方向、层级、禁止包、字段注入、执行面隔离） |
| `ForbiddenPatternScanTest` | 同上 | 表驱动正则扫描 `src/main/java`，13 条规则 |
| `ConfigCredentialScanTest` | 同上 | 扫描 `*.yml/*.properties`，5 条凭证规则 |
| `MigrationGuardTest` | 同上 | 比对迁移文件 checksum 与基线清单 |

> 已作为 Maven 模块接入 `platform/pom.xml`：**`mvn verify` 即执行，违规即构建失败**。
> 全部依赖 JUnit 5 + ArchUnit（只需引入 `archunit-junit5`，约 2MB）。

---

## 4. 落地顺序

| 优先级 | 规则 | 理由 |
|---|---|---|
| **P0（第一天）** | A1–A4（依赖方向）、R01–R03（shell/SQL）、C1–C3（凭证）、M1（迁移锁） | 这几条违反一次就是事故 |
| P1（第一迭代） | A5（执行面隔离）、R04–R06、R08、R10 | 一致性问题，越早越省 |
| P2（第二迭代） | R07、R09、R13、A6 | 锦上添花，但能持续防退化 |

> **不要一次上全**。P0 五条能拦住 80% 的严重问题；一次上 20 条会导致大量误报，然后团队集体关掉检查。

## 5. 误报与豁免

```java
// spec-ignore: R06 该字段是比率（0–1），不是金额，用 double 是有意为之
private double thresholdRatio;
```

| 规则 | 说明 |
|---|---|
| 豁免 MUST 带规则号 + 原因，写在同一行或上一行 | 无原因视为无效豁免 |
| 同一规则在同一模块被豁免 > 5 次 | 触发评审：是规则有问题还是代码有问题 |
| 豁免 MUST 登记到项目规约 §13 | 否则下次重构又出现 |

## 6. CI 集成（无额外服务）

```yaml
# 自研流水线 / 任意 CI 都适用
- name: verify
  run: ["mvn", "-B", "-q", "verify"]
```

产物：

| 文件 | 内容 |
|---|---|
| `target/surefire-reports/*.txt` | 逐条规则结果 |
| 失败信息格式 | `[R06] src/main/java/.../OrderBo.java:42 金额字段使用了 double` |

> 失败信息 MUST 含 **规则号 + 文件:行 + 规约条款**，否则开发者不知道去改什么。

## 7. 检查器自身也要被检查

| 规则 | 做法 |
|---|---|
| 每个检查规则 MUST 有"能抓到"的用例 | `src/test/resources/fixtures/` 放**故意违规**的样例文件，断言检查器能命中 |
| 防止规则失效（正则写错、路径改了） | fixtures 测试失败即报警 |
| 规则新增 MUST 同步更新本文 §2 映射表 | 评审时核对 |
