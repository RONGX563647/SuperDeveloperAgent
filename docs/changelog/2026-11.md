## 2026-11-15 · 调度并行化与上下文治理

- **新增 `workspace_dispatch`（DAG 并行）**：调度 Agent 一次传入节点数组（`depends_on/required/timeout_seconds`），无依赖节点并行派发、依赖满足后继续，主循环只等任意一个完成；N 个独立目标总耗时≈最慢节点，不再逐个 60 秒串行。循环依赖在派发前拒绝，单节点超时会取消对应运行。
- **提前终止**：必需节点失败且 `abort_on_failure=true` 时停止派发剩余节点；必需节点全部成功后不再派发可选节点，并取消在跑的可选节点；依赖失败的链路统一 `SKIPPED`（不占运行配额）。
- **前缀缓存**：`agent.model.prefix-cache`（默认开）将稳定的系统提示 + 工具 schema 标记为可复用（`cache_control`），后续轮次只计增量。
- **语义缓存**：只读工具结果按 `project|env|worktree|user + 工具 + 归一化参数` 缓存（Jaccard ≥ 0.9、TTL 90s、LRU 512）；写工具成功即清空同 scope；`ToolCatalog` 装配阶段统一包装，工具名/schema 不变。
- **上下文精益**：工具输出统一上限 `agent.tools.max-output-chars`（12000）；会话历史落盘前按 `agent.context.max-chars/keep-messages`（60000/24）裁剪，保留开头 SYSTEM 提示且不破坏 tool_use/tool_result 配对。
- **提示词**：调度 Agent 明确「多目标用 DAG 一次派发」「拿到足够信息立即结束本轮」。
- **DAG 全局超时**：`max_duration_seconds`（默认 600，上限 1800）约束整张 DAG；到点取消在跑节点、未开始节点 `SKIPPED`，返回已完成的部分结果并说明原因。
- **服务端上限**：`agent.workspace.dispatch.max-parallel` / `max-duration-seconds` 在 `ConversationManager` 收口，模型传入值只能被收紧。
- **SSE 保活**：调度对话默认 10 分钟（`agent.chat.super-timeout-ms`）、普通对话 3 分钟（`agent.chat.timeout-ms`）；`SseHeartbeat` 每 15 秒发注释行，发送统一加锁，超时/断开取消上游并释放并发配额。
- **缓存可观测**：`workspace_snapshot` 末尾附带 `tool_cache: hits/misses/hitRate/invalidations/size`。
- **影响面**：`agent-domain`（Dispatch* 记录 + 端口方法）、`agent-runtime`（调度器）、`agent-tools`（新工具 + 缓存装饰）、`agent-infra`（上下文裁剪）、`agent-gateway`（SSE 心跳/超时）；新增配置键见 Code Wiki §10.1；见 [ADR-0007](../adr/0007-DAG并行调度与三级上下文治理.md)。
- **验证**：`WorkspaceDispatchSchedulerTest`（含全局超时/参数收敛）、`ToolResultCacheTest`、`ConversationContextTrimmerTest`、`DispatchNodeParamBindingTest`、`ConversationManagerTest` 通过；ArchUnit A1-A9 与禁用模式扫描通过。

## 2026-11-12 · 安全与治理

- **新增统一运行账本**：`RunKind`×`RunState`，工作区/修复/流水线/发布双写 `_platform/run_ledger.db`；启动恢复只标记「RUNNING 超 5 分钟」为 INTERRUPTED；新增 `GET /api/v1/run-ledger`（见 [ADR-0004](../adr/0004-统一运行账本而非重写编排.md)）。
- **新增 `DangerousActionPolicy`**：破坏性动作（`rm -rf`、`drop table`、`git reset --hard`、`migrate`、`rollback` 等）即使在 dev/test 也要求人工确认；同动作 10 分钟最多 3 次（E-709，见 [ADR-0005](../adr/0005-安全边界放在平台层.md)）。
- **限流可跨实例**：`AgentStreamLimiter` 抽象为接口，`memory`（默认）/`jdbc`（SQLite 租约，TTL 10 分钟）可切；超限 429。
- **补丁匹配容错**：`PatchApplier` 四级匹配（精确 → 换行归一 → 忽略缩进 → 唯一子串），失败返回结构化原因，`FixStage` 回灌重试最多 2 次。
- **调度 Agent 只读答题**：`supervisorToolkit` = 会话/任务管理 + 全部只读工具，无文件/命令/补丁/部署能力。
