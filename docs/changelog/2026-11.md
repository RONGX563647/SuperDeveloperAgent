## 2026-11-13 · 性能与健壮性

- SQLite 每库连接上限 4 → 8；`UserStore`/`GiteeAccountStore` 改用连接池（登录与凭据读取不再每次打开文件）。
- 工作区事件总线改 `directBestEffort`：慢订阅者丢弃事件而非无界缓冲（事件非真相，真相在 SQLite）。
- 前端：会话历史写 localStorage 合并为 800ms 一次；流式自动滚动合并到 `requestAnimationFrame`。
- 治理库统一 `GovernanceDb`（WAL + `busy_timeout=5000`），并发写不再直接 `database is locked`。
- 运行账本增加 30 天终态清理（`GovernanceCleanupJob`）。
- 启动参数增加 `--enable-native-access=ALL-UNNAMED`（JDK 24+ 消除 sqlite-jdbc 受限方法告警）。
- **验证**：mvn install 全模块；governance 21、infra 75、gateway 定向 31 测试通过；health/login/SSE 实测。

## 2026-11-12 · 安全与治理

- **新增统一运行账本**：`RunKind`×`RunState`，工作区/修复/流水线/发布双写 `_platform/run_ledger.db`；启动恢复只标记「RUNNING 超 5 分钟」为 INTERRUPTED；新增 `GET /api/v1/run-ledger`（见 [ADR-0004](../adr/0004-统一运行账本而非重写编排.md)）。
- **新增 `DangerousActionPolicy`**：破坏性动作（`rm -rf`、`drop table`、`git reset --hard`、`migrate`、`rollback` 等）即使在 dev/test 也要求人工确认；同动作 10 分钟最多 3 次（E-709，见 [ADR-0005](../adr/0005-安全边界放在平台层.md)）。
- **限流可跨实例**：`AgentStreamLimiter` 抽象为接口，`memory`（默认）/`jdbc`（SQLite 租约，TTL 10 分钟）可切；超限 429。
- **补丁匹配容错**：`PatchApplier` 四级匹配（精确 → 换行归一 → 忽略缩进 → 唯一子串），失败返回结构化原因，`FixStage` 回灌重试最多 2 次。
- **调度 Agent 只读答题**：`supervisorToolkit` = 会话/任务管理 + 全部只读工具，无文件/命令/补丁/部署能力。
