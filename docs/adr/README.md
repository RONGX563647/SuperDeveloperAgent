## 何时需要写 ADR

- 新增/替换 Portal 入口、编排引擎、存储方案、鉴权模型；
- 改动「谁能写、写到哪、如何确认」这类安全边界；
- 引入外部依赖并影响部署形态（MCP、容器运行时、向量库、Wiki 同步）；
- 明确决定「不做某件事」且后人容易反复提议的（同样值得记录）。

不需要 ADR：纯重构、文案/样式、局部性能优化（写进 Code Wiki 即可）。
